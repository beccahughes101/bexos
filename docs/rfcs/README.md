# BexOS RFCs

RFCs record long-term designs, including implementation notes and future work.
See [RFC 0001](0001/README.md) for the structure and authoring conventions, and
[implementation guides](../README.md) for detailed subsystem documentation.
Each RFC has a dated `CURRENT.md` companion covering implementation, gaps, and
validation evidence.
An RFC number does not indicate approval or implementation status.
